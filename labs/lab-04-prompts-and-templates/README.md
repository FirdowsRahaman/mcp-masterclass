# Lab 4: Prompts & Templates

## Objective
Learn how to use the third MCP primitive: **Prompts**. You will build a server that provides reusable, standardized instructions to help AI models execute specific tasks perfectly every time.

## Why Prompts?
Instead of hoping users copy/paste the right instructions into Claude, you can host "Templates" directly on the MCP server. This is incredibly useful for standardizing things like code reviews, PR generation, or log analysis.

## Step 2: Implementing a Prompt Server

Create `prompt_server.py`:

```python
# prompt_server.py
from mcp.server.fastmcp import FastMCP
from mcp.types import PromptMessage, TextContent

mcp = FastMCP("prompt-server")

# Define a prompt template with arguments
@mcp.prompt()
def review_code(language: str, strictness: str = "high") -> list[PromptMessage]:
    """A standardized prompt template for reviewing code."""
    
    # 1. Construct the exact instructions we want the LLM to follow
    instruction = f"""
    You are an expert {language} developer. Please review the provided code.
    Your strictness level is set to: {strictness}.
    
    Please ensure you:
    1. Check for security vulnerabilities
    2. Check for performance bottlenecks
    3. Ensure PEP-8/standard formatting
    """
    
    # 2. Return it as a list of PromptMessage objects
    return [
        PromptMessage(
            role="user",
            content=TextContent(type="text", text=instruction)
        )
    ]

if __name__ == "__main__":
    mcp.run()
```

## Step 3: Test the Prompt Template

1. Start the Inspector:
   ```bash
   mcp-inspector python prompt_server.py
   ```
2. Open the Inspector in your browser.
3. Navigate to the **Prompts** tab. You should see your `review_code` prompt listed.
4. Fill in the arguments:
   - `language`: "Python"
   - `strictness`: "insane"
5. Click **Get Prompt**.
6. The Inspector will show you the exact message payload generated by the server. In a real AI client like Claude Desktop, the user would see this prompt as a slash command (e.g., `/review_code`), and selecting it would instantly populate the chat window with this robust instruction set!
